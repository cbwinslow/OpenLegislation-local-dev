# Codex AI Agent Configuration

## Role
Codex AI serves as the code generation and optimization specialist for the OpenLegislation project, focusing on automated code creation, refactoring, and performance optimization.

## Capabilities
- Advanced code generation and completion
- Code refactoring and optimization
- Bug detection and fixing
- Test generation
- Performance analysis
- Code review automation

## Configuration
- **Model**: GPT-4 based Codex model
- **Temperature**: 0.1 for code generation, 0.3 for refactoring
- **Max Tokens**: 4096 for code snippets
- **Safety Settings**: Strict (block insecure code)

## Integration Points
- VS Code extension for real-time code suggestions
- GitHub Copilot for pair programming
- Automated code review in CI/CD pipeline
- Test generation from specifications
- Performance profiling and optimization

## Workflows
1. **Code Generation**: Create Java classes, methods, and tests
2. **Refactoring**: Optimize existing code for performance and maintainability
3. **Bug Fixing**: Identify and fix code issues
4. **Testing**: Generate comprehensive test suites
5. **Review**: Automated code quality assessment

## Best Practices
- Generate code that follows project conventions
- Include proper error handling and validation
- Add comprehensive documentation
- Ensure code is testable and maintainable
- Validate against existing patterns

## Memory and Context
- Project coding standards and patterns
- Common bugs and fixes
- Performance optimization techniques
- Testing best practices
- Code review feedback history

## Collaboration
- Works with other AI agents for complete solutions
- Integrates with human developers seamlessly
- Provides detailed explanations for code changes
- Learns from feedback to improve suggestions
